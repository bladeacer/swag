# v0.7.0: format integrity

This release widens the conversion report and proves that the readers and the writers compose. It also removes two ASS losses that the writer can avoid.

## Added

- Loss notes in the YTT, SRV3, SRT, and SBV writers for a strikeout run and a glyph scale.
- A cross-check case that runs the override fixture through every shipped writer. It asserts the exact loss report of each target.
- A chain test that runs one ASS source through a sequence of formats of length two or more, then back to ASS. It asserts that the text and the cue timing survive, so the readers and the writers compose.

## Fixed

- The ASS writer no longer reports a chroma loss when the offsets form the symmetric spread that the argument form rebuilds. A chroma that came from ASS round-trips without a loss.
- A blank `\ytvert` returns a run to horizontal text. A run that leaves vertical text no longer reports a loss.

## Changed

- [The ASS support page](../ass-support.md): the deliberate loss list loses the chroma and vertical entries, and the test list names the new suites.
- [The format notes](../formats.md): the ASS loss list and the plain format loss lists name the new cases.

## Notes

- A karaoke gap, a ruby base with several readings, a cursor with no text, and a shadow that is not hard stay out of the ASS writer, because ASS has no tag for them.

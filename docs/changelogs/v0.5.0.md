# v0.5.0: ASS writer

The ASS writer: the intermediate representation writes back to Advanced SubStation Alpha. It emits the Tier 1 to Tier 3 tags, with a loss report for the features that ASS cannot express.

## Added

- `internal/formats/ass`: a writer that renders the IR as a Script Info section, a V4+ Styles section, and an Events section. It writes the play resolution, the style table in a fixed field order, and one Dialogue line per cue.
- Tier 1 tag emission: the character styles, the four colour channels with their alpha tags, `\bord`, the `\k` karaoke timing, `\r`, `\an`, and `\pos`.
- Tier 2 tag emission: the `\move`, `\fad`, `\fade`, and `\t` effects, and the `\ytshake`, `\ytchroma`, and `\ytkt` YouTube tags.
- Tier 3 tag emission: the `\ytruby`, `\ytvert`, `\ytpack`, `\ytdir4`, and `\ytdir6` layout tags.
- Outline, shadow, and box emission. An outline colour and a background box both use the `\3c` and `\3a` tags. A hard shadow uses `\4c` and `\4a`, and a box style writes BorderStyle 3.
- A semantic round-trip test over the committed fixtures. It compares colours, timing, spans, layout, and animations, and it allows the style names to flatten and the runs to re-split.
- A cross-check suite over every shipped writer, run from one ASS source. It asserts the exact loss report of each target format.
- Loss notes for the features that ASS cannot express. The writer reports a shadow that is not hard, and a chroma effect with more than one copy. It also reports a run that leaves vertical text, a karaoke gap, and a ruby base with more than one reading.
- `docs/architecture.md`: the packages, the intermediate representation, the format matrix, and the ASS tag tiers, split out of the roadmap.
- [Third-party notices](../third-party-notices.md): the inspiration sources, the vendored `simple-english` skill, the Go dependencies, and the standards.

## Changed

- `pkg/sub`: the `ass` entry now writes as well as reads, so ASS is a conversion target.
- The ASS reader keeps a fade in `Cue.Layout`. It remembers whether an inline tag changed the outline or shadow colour, so the writer emits the matching tag.
- The writer emits the vertical mode and the reading direction as span-level changes. A direction now applies from the tag onward, and not to the whole line.
- [The format notes](../formats.md) gain the ASS writer and its degradation notes.
- The GoReleaser release body links the changelog file of the tag. The `make tag` message links too.
- `make tag` reads the highest changelog version and offers it as the default. The prompt still accepts an override.
- Every markdown link carries a human-readable alias.
- Statement coverage sits at 100%. The `Makefile` and the CI workflow enforce that floor.
- Prose follows the vendored `simple-english` skill. A CHECK pass shortened the long sentences and removed the passive clauses from the documentation.

## Removed

- No em-dash remains in the prose or the code. [The contributor rules](../../AGENTS.md) ban it.
- The YTT reader and writer, the ASS tag parser, and the CLI lost their dead branches.

## Fixed

- The `Makefile` `test` target absorbed the `cover` recipe. The two targets are separate again.

## Notes

- ASS carries one outline width and one shadow per line. A span override writes the matching tag, and a feature with no tag reports a loss.
- The writer keeps the text of every cue. A format that cannot express a visual feature still carries the words through.

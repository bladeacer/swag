# v0.4.0: ASS reader

The ASS reader: Advanced SubStation Alpha files read into the intermediate representation, including styles, karaoke, animations, ruby text, vertical layout, and direction.

## Added

- `internal/richtext`: one parser for the ASS override tag syntax, shared by the reader and, later, the writer. It splits an event line into runs of tags and text. It resolves the `\n`, `\N`, `\h`, and `\\` escapes, and reads both the bare-value tag form and the parenthesised argument form.
- `internal/formats/ass`: a reader for the Script Info, V4+ Styles, and Events sections. It reads the play resolution, the style table, and the dialogue lines.
- Style-to-IR mapping. The reader treats the style named `Default`, or the first style, as the baseline. It flattens the style of a cue onto the spans of that cue.
- Tier 1 tags: `\b`, `\i`, `\u`, `\fn`, `\fs`, `\c`, `\1c`, `\2c`, `\3c`, and `\4c`. The list also covers `\1a` to `\4a`, `\alpha`, `\k`, `\K`, `\kf`, `\ko`, `\r`, `\an`, and `\pos`. Karaoke spans keep the timing of their syllable and the unsung colour of the style.
- Tier 2 effects: `\move`, `\fad`, `\fade`, `\t`, `\ytshake`, `\ytchroma`, and the `\ytkt` karaoke types. `\ytsup`, `\ytsub`, and `\ytsur` set the script offset.
- Tier 3 tags: `\ytruby` with the over and under positions, `\ytvert` modes 9, 7, 1, and 3, `\ytpack`, `\ytdir4`, and `\ytdir6`.
- Karaoke types in the IR. `model.Animation` carries an optional `Karaoke` value for the fade, glitch, and cursor kinds.
- Fixtures written fresh for this project: `karaoke.ass`, `colour.ass`, and `cjk.ass` under `internal/formats/ass/testdata/`.
- `docs/formats.md`: the support matrix and the degradation notes for every shipped format.
- The `ass` entry in the registry, which reads the `ass` and `ssa` extensions.

## Notes

- A tag outside the supported tiers is accepted and ignored.
- The outline colour of a style that is not the baseline style becomes a glow shadow on the span. The IR carries an outline colour only on the style.
- A karaoke syllable keeps its window when a colour tag splits it, so several spans can share one karaoke window.

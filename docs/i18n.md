# Internationalisation

Every user-facing string of the command line comes from the message catalogue in [the i18n package](../internal/i18n/i18n.go). The command never formats display text inline. One file per language, one map per file, and the default locale is `en-GB`.

## The catalogue

A message is a key and a value. The keys are constants, so a typo is a compile error rather than a missing string:

```go
const (
	MsgConvertStart   Key = "convert.start"
	MsgConvertSuccess Key = "convert.success"
	MsgConvertLosses  Key = "convert.losses"
)

var enGB = map[Key]string{
	MsgConvertStart:   "Converting %s to %s format.",
	MsgConvertSuccess: "Wrote %s.",
	MsgConvertLosses:  "Features the target format does not carry (%d):",
}
```

A lookup is `T.S(key)` for a whole message and `T.F(key, args...)` for a message with placeholders. The message carries one placeholder per value, so a translator sees the whole sentence and the order of the values. A sentence is never built by joining fragments.

An unknown key returns the key itself. A missing translation therefore stays visible in the output instead of printing an empty line.

## Locale selection

The locale comes from the `--locale` flag, and `SWAG_LOCALE` sets the default for the flag. The value is a language tag, for example `en-GB` or `fr-FR`.

A tag resolves in three steps:

1. An exact match of the tag, ignoring case and treating `_` as `-`. `en_GB` and `en-gb` both select `en-GB`.
2. The language part of the tag, when a catalogue is registered under the bare language. This step matters only when a catalogue uses such a tag.
3. The default locale, `en-GB`.

So `fr-FR`, `fr-fr`, and `FR-FR` select the French catalogue, and `de-DE` selects `en-GB`, because no German catalogue is registered. A key that the selected catalogue does not carry falls back to `en-GB` at lookup time, so a partly translated locale stays readable.

## Add a language

1. Create a file under [the i18n package](../internal/i18n), for example `de.go`, with the locale tag and the map:

```go
const germanLocale Locale = "de-DE"

var deDE = map[Key]string{
	MsgConvertStart: "Konvertiere %s in das Format %s.",
}

func init() {
	Register(germanLocale, deDE)
}
```

2. Translate every key of the default catalogue. [The second locale test](../internal/i18n/i18n_test.go) reads both maps and fails when a key is missing or unknown, so a partial catalogue fails the build.
3. Add the locale to [the third-party notices](third-party-notices.md) only when the text comes from another work. Translation of our own messages needs no notice.

No change to the command is needed. `Supported()` reports the registered locales, and the flag already accepts the new tag.

## Message rules

- Write a complete sentence. One message, one point.
- Give translators the whole sentence with one placeholder per value. Never join two messages to build one sentence.
- Keep the placeholders of a translation in the same count as the default catalogue: `T.F` formats with the values the caller passes.
- Follow [the simple-english skill](../skills/simple-english/SKILL.md), with British English spelling.
- Keep identifiers, flag names, format names, and quoted errors unchanged, in every locale.
- Do not write em-dashes or en-dashes in any message.

Messages cover the command line only. The library returns errors and loss reports, which are not translated. [The usage page](usage.md) shows where each message appears.

## Tests

[The i18n tests](../internal/i18n/i18n_test.go) cover the tag resolution, the register and lookup path, the key fallback, the locale report, and the completeness of the second locale. The message catalogue sits at 100 percent statement coverage with the rest of the module.

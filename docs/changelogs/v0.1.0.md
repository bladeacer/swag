# v0.1.0: foundation

The foundation release: the intermediate representation, the i18n skeleton, and the build tooling. No subtitle formats are readable yet.

## Added

- Intermediate representation in `internal/model`: `Colour` (RGBA), `Cue`, `TextSpan`, `Style`, and `Layout`. It also carries vertical text modes, ruby text, script offsets, karaoke span timing, multi-shadow effects, and style resolution.
- Message catalogue in `internal/i18n` with the `en-GB` locale.
- Release configuration in `.goreleaser.yaml` for linux, darwin, and windows (amd64, arm64) and js/wasm, compiled with `CGO_ENABLED=0` and linker flags `-s -w`. The wasm build activates when the browser demo lands at v1.0.0.
- Development tooling: `.air.toml` for hot reload, a `Makefile` (build, test, cover, vet, fmt), and a CI workflow with a 75% coverage floor.
- Project governance documents: `AGENTS.md`, `ROADMAP.md`, the documentation index, and per-release changelog files.
- Vendored `simple-english` skill (based on [the SimpleEnglish skill](https://github.com/AminBlg/SimpleEnglish), MIT) with a British English project override for all documentation.
- Apache-2.0 licence and third-party notices (`docs/third-party-notices.md`) with attribution to YTSubConverter as the source of inspiration.

# v0.2.0: plain formats

The first converting release: SubRip and SBV in and out, format auto-detection, and a working CLI.

## Added

- SubRip (`internal/formats/srt`) reader and writer: cue counters, inline italic and bold tags, multi-line cues, and timestamps with overflow hours. The writer reports every feature it drops, from karaoke timing to transparency, and renders ruby readings as bracketed text.
- SBV (`internal/formats/sbv`) reader and writer: comma-joined timestamps, multi-line cues, and the same loss reporting and ruby fallback.
- Public library entry point (`pkg/sub`): a format registry with a `Format` interface, and content and extension detection (`Identify`, `DetectFormat`). It also offers parsing (`Parse`), rendering with loss reports (`Render`), and a one-step `Convert`.
- Command line interface (`cmd/swag`) built on kong and pterm: `swag convert -i input -o output`, a `-f` format override, and `-v`/`-V` conversion reports. It writes to stdout when `-o` is omitted, and it carries a styled startup banner and a `--locale` flag. The message catalogue backs every string.
- `go install` support: `go install github.com/bladeacer/swag/cmd/swag@latest` builds the CLI with `CGO_ENABLED=0` and stripped symbols, and a `make install` target does the same from a clone.
- Makefile in the style of a release helper: `make help` as the default goal, plus `build`, `test`, `cover`, `cover-html`, `cover-verify`, `vet`, `fmt`, and `watch` (air). It also carries `release-test`, `snapshot`, `tag`, and `clean`.
- Release workflow (`.github/workflows/release.yml`): a pushed `v*` tag runs GoReleaser and publishes the GitHub release.
- Third-party notices moved to `docs/third-party-notices.md` with clickable links, and the vendored documentation skill moved to `skills/simple-english/`.

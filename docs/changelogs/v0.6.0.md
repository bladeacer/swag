# v0.6.0: ASS tag closure

This release closes the ASS feature list of YTSubConverter. It reads and writes the Aegisub overrides that the intermediate representation (IR) can express, and it documents the full list. The TTML, WebVTT, Kdenlive, and JSON1 formats land in the same release.

## Added

- `internal/model`: span overrides for shadow distance (`ShadowDepth`), strikeout (`Strikeout`), and glyph scale (`ScaleX`, `ScaleY`). The resolved span carries the effective values.
- `internal/formats/ass`: the reader and the writer handle the Aegisub tags `\shad`, `\xshad`, `\yshad`, `\a`, `\s`, `\fscx`, and `\fscy`.
- `\ytchroma` custom colours and alpha. The IR chroma carries a colour list and an alpha channel, and the writer emits the long argument form.
- The `\ytkt` cursor forms. The reader keeps the `LCursor` and `RCursor` side, the cursor tags, and the animated frames. The writer emits the static, tagged, and animated forms.
- `internal/formats/ass/testdata/overrides.ass`: a round-trip fixture for the new overrides.
- [The ASS support page](../ass-support.md): the YTSubConverter ASS feature list mapped onto the IR fields and the tests.

## Changed

- [The architecture page](../architecture.md): the ASS tier lists name the new tags.
- [The format notes](../formats.md): the ASS section names the new tags and links the support page.
- [The documentation index](../index.md): links the ASS support page.

## Fixed

- The comment headers of the ASS fixtures use a colon instead of an em-dash. [The contributor rules](../../AGENTS.md) ban the em-dash.

## Notes

- The reader maps `\xshad` and `\yshad` onto the one shadow distance of the IR, so the tag that appears last wins.
- The writer emits `\an` for an alignment, because the IR carries a numpad anchor.
- A chroma with more than one offset keeps a conservative loss note.
